  1. 01

    Env vars get inlined.

    Anything prefixed VITE_, NEXT_PUBLIC_ or REACT_APP_ is pasted into your bundle at build time. Put a secret there once and it ships to every visitor.

  2. 02

    Source maps publish your source.

    A forgotten .map file hands out your original code, comments and config files included. Watcher follows the map and scans what is inside it.

  3. 03

    Tokens sit in plain sight.

    Session tokens in localStorage, cookies without HttpOnly, a password prefilled in a form. Any script on the page can read them. So can Watcher.

Security model

0 Zero bytes leave your browser.

A security tool you don't have to trust blindly. Every guarantee below is enforced in code and checked on every build.

  • 01

    Local only

    The extension's own pages are forbidden from making network requests at all.

    connect-src 'none'
  • 02

    Read-only

    No writes to the page, its storage or cookies. Tests assert zero DOM changes per scan.

    0 mutations · CI-checked
  • 03

    XSS-safe popup

    Page content renders as text only. Any HTML injection throws before it can render.

    require-trusted-types-for 'script'
  • 04

    Minimal permissions

    No host permissions, no always-on scripts. Watcher runs only on the tab you choose.

    activeTab · scripting · storage
  • 05

    No secrets on disk

    Results live in memory and vanish with the tab. Accepted items are salted hashes.

    storage.session · SHA-256
  • 06

    Verifiable builds

    Reproducible zips with checksums and signed build provenance on every release.

    sha256 · attestation

FAQ

Questions, answered.

Something else? Open an issue

Is it safe to run on a production site?

Yes. Watcher only reads. It never changes the page, its storage or its cookies, it runs only when you press Scan, and it re-reads your own files from the browser cache where it can.

Does it send my code or findings anywhere?

No. There is no server, analytics or telemetry. The extension's pages are blocked from making network requests by their own security policy, and exports are saved only where you choose.

Can I scan sites I don't own?

Only with permission. Watcher is built for developers and testers checking applications they own or are authorised to assess, such as their own staging and production builds.

How is this different from gitleaks or trufflehog?

Those scan your repository. Watcher scans what actually reached the browser: values your bundler inlined at build time, source maps you published by accident, and tokens your app stores at runtime. Use both.

Will it find every secret?

No scanner can promise that. Vendor-format matches are reliable; keyword and entropy matches are marked "needs review". Treat anything Critical or High as compromised and rotate it.

Which browsers does it work in?

Chrome, Edge, Brave, Opera, Arc and other Chromium browsers from version 116.
